# design-source

Only the Figma capture script lives here now: `scripts/figma-capture.mjs`. The Figma frames are captured straight from the built site, so there is no second hand-written design to keep in sync. The old generator, design HTML, tokens and screenshots are in `archive/design-source-old/` (git-ignored, nothing deleted). Tokens live in one place: `site/src/styles/theme.css` (D-10).

How to re-capture the site into Figma: `docs/FIGMA-HANDOFF.md`.
